# BookReader-System-OOP
A console-based C++ application for reading books, built using OOP and MVC.

 Features
 Admin: Add new books and view profile.
Customer: Browse books, track reading progress (page & date), and navigate pages.

 Architecture
 Models: `User`, `Book`, `ReadingSession` (Data only).
Controllers: `UsersManager`, `BooksManager` (Logic only).
View: `BookReaderUI` (Console I/O).
